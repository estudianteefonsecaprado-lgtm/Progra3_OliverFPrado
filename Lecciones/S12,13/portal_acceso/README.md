# IN3014 - Semana 10 - Portal de Acceso

Laboratorio guiado de Programación III.

## Requisitos

- XAMPP
- Apache iniciado
- PHP 8

## Instalación

1. Copie la carpeta `portal_acceso` dentro de:

```
C:\xampp\htdocs\
```

2. Inicie Apache desde XAMPP.

3. Abra el navegador y acceda a:

```
http://localhost/portal_acceso/
```
