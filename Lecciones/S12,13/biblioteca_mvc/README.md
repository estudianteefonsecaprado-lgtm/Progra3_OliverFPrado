# Biblioteca MVC

Aplicación CRUD desarrollada en PHP utilizando el patrón MVC, MySQL y PDO.

## Requisitos

- XAMPP (Apache y MySQL)
- PHP 8 o superior

## Instalación

1. Copiar la carpeta `biblioteca_mvc` dentro de `htdocs`.
2. Abrir phpMyAdmin.
3. Crear la base de datos o importar el archivo:

   database/biblioteca_db.sql

4. Verificar que la base de datos se llame:

   biblioteca_db

5. Iniciar Apache y MySQL desde XAMPP.

## URL local

http://localhost/biblioteca_mvc/public/

## Base de datos

Nombre:

biblioteca_db

## Configuración

La conexión utiliza los siguientes datos:

- Host: localhost
- Usuario: root
- Contraseña: (vacía)

No se requiere ninguna configuración adicional.
